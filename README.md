# 【WIP】KeyPadManager
Provides a system for managing keyboard and gamepad operations for Unity.  
Unity向けのキーボードとゲームパッドの操作管理を行うシステムを提供します。  
  
実装するもの  
・キーボードとゲームパッドの入力を1つの判定で出来るようにする。  
・カーソルの当たる仕組みの作成  
　⇒カーソルターゲットと親のカーソル管理を作る。  
　　無限スクロールビュー系の場合用にメモリ内の仮想のリスト項目に対するカーソル操作もできるようにする。  
・対応するキーの文字とアイコン画像を取得できるようにする。  
・フッターにキーアサインを出す場合など用にデフォルトのキーとアイコン画像の定義をできるように。  
・キーボードとゲームパッド切り替え判定とれるように。  
・設定保存時に保存方法をカスタマイズできるようにフック出来る機能を追加する。
